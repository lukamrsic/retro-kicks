# Retro Kicks Archive

Retro Kicks Archive is a web application I built as a university project.

The application allows users to browse and filter a collection of sneakers, while an admin can manage the content through the application.

## Features

- Browse sneaker collection
- Filter sneakers by category
- Add and manage sneakers
- Archive functionality
- User authentication
- Database integration

## Technologies

- PHP
- MySQL
- HTML
- CSS


## Database

The application uses MySQL for storing users, sneakers and other application data.

## Running locally

The project can be run locally using XAMPP:

1. Clone the repository
2. Start Apache and MySQL in XAMPP
3. Import the database into phpMyAdmin
4. Place the project inside the `htdocs` directory
5. Open the application through `localhost`
